How to use this

  1. Before you trade an rToken while the market is shut, find it below. Compare Last against Fair value — the last regular-session close.
  2. Check the depth. Buy/sell depth is what the book can absorb before the price moves half a percent. Many rTokens hold under $25,000. If your order is larger than that, you are the market.
  3. Size your order. Pick an order size above the table and NOCTURNE shows how many slices it would take to fill without moving the price more than half a percent.
  4. Check the Noise score. High means this drift is unusually large for this stock. It ranks risk; it does not tell you which way Monday goes.
  5. Mind the clock. Bitget cancels every unfilled weekend limit order when the US market reopens — the countdown is above.
  6. Then trade on Bitget. Every symbol links to its own Bitget page.

No account, wallet or API key needed here. NOCTURNE is read-only: it never places an order, holds a key or touches a balance. It reads the same public market data anyone can, and hands you the numbers Bitget's own screen does not show. Agents can read it too — see the skill and the public API.

What this is not. It is not a forecast of Monday's price. We built and tested forecasting models walk-forward and they lost to the naive baseline. Only the unfitted model wins, by about 9% MAE on large caps, in 7 weekends out of 10. The Noise Score ranks execution risk; it does not predict direction.
The market. Bitget lists tokenized US equities that trade 24/7, but Nasdaq closes Friday 20:00 ET and reopens Monday 09:30 ET. For ~47 hours a week these assets have no external price anywhere — an internal matching engine is the only source.
The finding. Across 196 observations, 37 symbols and 13 weekends, we regressed the re-anchor return on the void-window return. For large caps: β = -1.003, t = -3.46 — essentially all weekend movement reverses. We call it Void Drift.
The method. Fair value during a dark session is the last regular-session close. Depth, spread and the ±10% limit band are read directly from the order book, not modelled.
