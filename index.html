The finding

For 47 hours a week, these stocks have no price anywhere on Earth.

Bitget lists tokenized US equities that trade around the clock. Nasdaq does not — it closes Friday 20:00 ET and reopens Monday 09:30. In between, an internal matching engine is the only source of a price, and it clears almost nothing.

Across 196 observations and 13 weekends we measured what happens to that movement once real liquidity returns. For large caps, essentially all of it reverses. We call it Void Drift.

The public record

Every weekend we publish two falsifiable claims before the US market reopens, with a SHA256 of the file committed to a public repository — a git timestamp cannot be back-dated. Then we grade them and publish the result, win or lose.

Claim 1 historically wins 7 weekends in 10. We state that in advance, so a single loss is a predicted outcome rather than a surprise. every prediction & hash · methodology

How to use this

  1. Find the rToken you are about to trade while the market is shut. Compare Last against Fair value — the last regular-session close.
  2. Check the depth. That is what the book absorbs before the price moves half a percent. Many rTokens hold under $25,000.
  3. Size the order. Pick an order size above the table and every row shows how many slices it would take to fill.
  4. Check the Noise score. High means this drift is unusually large for this stock. It ranks risk; it does not say which way Monday goes.
  5. Mind the clock. Bitget cancels every unfilled weekend limit order at the reopen.
  6. Then trade on Bitget. Every symbol links to its own page.
No account, wallet or API key needed here. NOCTURNE is read-only: it never places an order, holds a key or touches a balance. It reads the same public market data anyone can and hands you the numbers Bitget's own screen does not show. Agents can read it too — see the skill and the public API.
What this is not. It is not a forecast of Monday's price. We built and tested forecasting models walk-forward and they lost to the naive baseline. Only the unfitted model wins, by about 9% MAE on large caps, in 7 weekends out of 10.
Method. Fair value during a dark session is the last regular-session close. Depth, spread and the ±10% limit band are read directly from the order book, not modelled. Scores are produced only in the weekend windows the model was calibrated on.
The finding. Regressing the re-anchor return on the void-window return, large caps: β = −1.003, t = −3.46, R² 0.131, n 81.
